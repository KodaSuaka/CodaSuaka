# Dokumen Legal — CodaSuaka

Folder ini berisi dokumen legal siap cetak untuk aplikasi CodaSuaka: EULA dan Surat Perjanjian Penggunaan & Berlangganan.

| Dokumen | Format | Kegunaan |
|---|---|---|
| `EULA-CodaSuaka.docx` / `.pdf` | Perjanjian Lisensi Pengguna Akhir | Ketentuan penggunaan aplikasi yang mengikat setiap Pengguna (Owner, Super Admin, Manajemen, Keuangan, Staff) sejak Aplikasi digunakan. Tidak memerlukan tanda tangan — berlaku otomatis saat Aplikasi diakses. |
| `Surat-Perjanjian-Penggunaan-dan-Berlangganan-CodaSuaka.docx` / `.pdf` | Surat Perjanjian (kontrak) | Template kontrak berlangganan antara Penyedia (PIHAK PERTAMA) dan Instansi Pelanggan (PIHAK KEDUA), berisi rincian Paket Berlangganan, biaya, jangka waktu, hak/kewajiban, serta kolom tanda tangan & materai. Perlu diisi dan ditandatangani per pelanggan. |

## Cara menggunakan Surat Perjanjian

1. Buka file `.docx` di Word/LibreOffice untuk mengisi bagian bertitik-titik (`……`): nomor surat, identitas PIHAK PERTAMA & PIHAK KEDUA, dan rincian Paket Berlangganan (Pasal 3) sesuai data pada tabel `pakets`/`transaksi_pakets`.
2. Cetak dokumen yang sudah terisi, tempelkan meterai sesuai ketentuan bea meterai yang berlaku, lalu tanda tangani oleh kedua pihak.
3. File `.pdf` disediakan untuk pratinjau cepat atau cetak langsung tanpa perlu mengedit — cocok jika hanya perlu contoh/template kosong.

## Catatan

Dokumen ini adalah draf template umum berdasarkan model bisnis CodaSuaka (multi-tenant, manajemen karyawan, keuangan, dan Paket Berlangganan berbayar dengan `harga`, `durasi_hari`, `max_outlet`, `max_karyawan_per_outlet`). Disarankan untuk direview oleh konsultan hukum sebelum digunakan secara resmi, terutama terkait domisili pengadilan (Pasal 12 EULA / Pasal 12 Surat Perjanjian), bea meterai, dan kepatuhan UU PDP.
